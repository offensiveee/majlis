# تركيب «مجلس» على تلفزيون سامسونج

[English](../en/install-samsung.md) · [كل التلفزيونات](install.md) · [خلّ الذكاء الاصطناعي يساعدك](ai-help.md)

## اللي تحتاجه

> **باختصار:** حساب سامسونج، وكمبيوتر فيه Tizen Studio و Node.js على نفس شبكة التلفزيون، وتقريباً ٣٠ دقيقة أول مرة.

- تلفزيون سامسونج ذكي بنظام Tizen (موديلات ٢٠١٧ وبعدها)
- كمبيوتر (ويندوز أو ماك أو لينكس) على **نفس شبكة** التلفزيون
- [حساب سامسونج](https://account.samsung.com) مجاني
- [Tizen Studio](https://developer.samsung.com/smarttv/develop/getting-started/setting-up-sdk/installing-tv-sdk.html) مع إضافات التلفزيون
- [Node.js 18 أو أحدث](https://nodejs.org) و [Git](https://git-scm.com)

### وش تسوي نسخة سامسونج ووش ما تسوي

سامسونج ما تسمح للتطبيقات تخلي مساعد شغّال بالخلفية. فعلى سامسونج تحصل الشاشة كاملة: مواقيت الصلاة وتنبيهها و«مجلس» مفتوح، وإذاعة القرآن، والتاريخ الهجري، والمناسبات، ووضع الهدوء، والثيمات والإطارات، وبطاقة واي فاي الضيوف. لكن **ما فيها** تطبيق الجوال، ولا الإشعارات فوق التطبيقات، ولا زر الرئيسية. الإعدادات تتغير من التلفزيون في **مجلس ← الإعدادات**، والاسم والترحيب والمدينة والواي فاي تكتبها في ملف قبل التركيب (الخطوة ٥).

## ١. شغّل وضع المطوّر في التلفزيون

١. اعرف عنوان IP حق **الكمبيوتر** (ويندوز: `ipconfig`، ماك: إعدادات النظام ‹ Wi-Fi ‹ التفاصيل).
٢. في التلفزيون افتح **التطبيقات (Apps)**.
٣. بالريموت اكتب **١ ٢ ٣ ٤ ٥**، وبتنفتح نافذة وضع المطوّر.
٤. فعّل **Developer mode**، واكتب عنوان IP حق **كمبيوترك**، واضغط **موافق**.
٥. طفّ التلفزيون وشغّله (اضغط زر التشغيل مطوّل لين يعيد التشغيل).

عنوان التلفزيون نفسه في **الإعدادات ‹ عام ‹ الشبكة ‹ حالة الشبكة ‹ إعدادات IP**.

## ٢. ركّب Tizen Studio

١. نزّل وركّب [Tizen Studio](https://developer.tizen.org/development/tizen-studio/download).
٢. افتح **Package Manager** (ينفتح بعد التركيب، أو من قائمة Tools في Tizen Studio).
٣. من **Main SDK** ركّب **Tizen SDK tools**.
٤. من **Extension SDK** ركّب **TV Extensions** (أحدث إصدار) و **Samsung Certificate Extension**.

## ٣. وصّل التلفزيون

١. في Tizen Studio افتح **Tools ‹ Device Manager**.
٢. اختار **Remote Device Manager**، واضغط **+**، واكتب اسم وعنوان IP حق **التلفزيون** (المنفذ 26101).
٣. فعّل الاتصال، والتلفزيون يطلع في القائمة.

## ٤. سوّ شهادتك

سامسونج ما تركّب إلا تطبيقات موقّعة لتلفزيونك.

١. افتح **Tools ‹ Certificate Manager** واضغط **+**.
٢. اختار **Samsung** ثم **TV**.
٣. سمّ الملف **majlis**.
٤. سوّ **Author certificate** (اختار كلمة مرور واحفظها).
٥. سجّل دخول بحساب سامسونج لما يطلب.
٦. سوّ **Distributor certificate**. والتلفزيون متصل، رقمه (DUID) ينضاف لحاله.
٧. خلّ **majlis** هو الملف المفعّل.

## ٥. إعداداتك

<div dir="ltr">

```bash
git clone https://github.com/offensiveee/majlis.git
cd majlis
npm install
cp majlis.config.example.json majlis.config.json
```

</div>

افتح `majlis.config.json` واكتب اسم المجلس، وسطر الترحيب، والمدينة (مثل `riyadh` أو `jeddah` أو `kuwait` أو `dubai`، والقائمة كاملة في `src/app/data.js`)، وواي فاي الضيوف.

## ٦. البناء والتركيب

<div dir="ltr">

```bash
npm run samsung -- --install <tv-ip>
```

</div>

هذا يبني التطبيق، ويوقّعه بملف **majlis**، ويركّبه. بعدها «مجلس» يطلع في **التطبيقات** بالتلفزيون، وتقدر تقدّمه لأول الشريط.

إذا Tizen Studio مو في مكانه الافتراضي، قل للسكربت وين:

<div dir="ltr">

```bash
TIZEN_STUDIO=/path/to/tizen-studio npm run samsung -- --install <tv-ip>
```

</div>

وعشان تبني الحزمة الموقّعة بس: `npm run samsung -- --package`.

## التحديث

عدّل `majlis.config.json` إذا تبي، وكرر الخطوة ٦.

## الحذف

في التلفزيون: **التطبيقات**، وقف على **مجلس**، واضغط موافق مطوّل (أو اختار الإعدادات) ‹ **حذف**.

## مشاكل

- **ما يتصل بالتلفزيون**: العنوان اللي كتبته في وضع المطوّر بالتلفزيون لازم يكون عنوان كمبيوترك، ولازم تعيد تشغيل التلفزيون بعدها.
- **أخطاء «Certificate» أو «signature»**: تأكد إن ملف **majlis** مفعّل، وإنك سويته والتلفزيون متصل عشان يكون رقم التلفزيون (DUID) فيه.
- **وضع المطوّر طفى لحاله**: بعض الموديلات تطفيه بعد تحديث النظام. كرر الخطوة ١، و«مجلس» يبقى مركّب.
