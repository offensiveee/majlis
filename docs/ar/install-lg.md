# تركيب «مجلس» على تلفزيون LG

[English](../en/install-lg.md) · [كل التلفزيونات](install.md) · [خلّ الذكاء الاصطناعي يساعدك](ai-help.md)

أول مرة تاخذ تقريباً عشر دقايق. تسويها مرة وحدة لكل تلفزيون، وبعدها التلفزيون يشغّل «مجلس» لحاله.

## اللي تحتاجه

> **باختصار:** حساب مطوّر من LG (مجاني)، وكمبيوتر على نفس الشبكة فيه Node.js و Git، وريموت التلفزيون. بدون روت.

- تلفزيون LG بنظام webOS 6 أو أحدث (موديلات ٢٠٢١ وبعدها). الموديلات الأقدم (webOS 4–5) ممكن تشتغل.
- كمبيوتر (ويندوز أو ماك أو لينكس) على **نفس شبكة** التلفزيون
- [Node.js 18 أو أحدث](https://nodejs.org) و [Git](https://git-scm.com)
- حساب مطوّر مجاني من LG، تسويه من [webostv.developer.lge.com](https://webostv.developer.lge.com) (فوق يمين: Sign in ثم Create account)

## ١. شغّل وضع المطوّر على التلفزيون

١. افتح **LG Content Store** (أو **التطبيقات**) في التلفزيون، وابحث عن **Developer Mode** ونزّله.
٢. افتح **Developer Mode** وسجّل دخول بحساب المطوّر.
٣. فعّل **Dev Mode Status**، والتلفزيون بيعيد التشغيل.
٤. افتح **Developer Mode** مرة ثانية. بيطلع لك **عنوان IP** حق التلفزيون و**رمز (Passphrase)**. خلّ الشاشة مفتوحة.
٥. فعّل **Key Server**.

> وضع المطوّر عادةً يطفي لحاله بعد ٥٠ ساعة. «مجلس» يجدده تلقائياً كل ١٢ ساعة طالما التلفزيون متصل بالإنترنت، فما تحتاج تضغط **Extend**.

## ٢. نزّل «مجلس» على الكمبيوتر

<div dir="ltr">

```bash
git clone https://github.com/offensiveee/majlis.git
cd majlis
npm install
```

</div>

## ٣. أضف التلفزيون

اختار اسم قصير للتلفزيون (مثل `majlis` أو `living` أو `bedroom`) واستخدم عنوان IP من الخطوة ١:

<div dir="ltr">

```bash
npm run setup -- --name majlis --ip 192.168.1.40
```

</div>

السكربت يمشي معك في ثلاث خطوات:

١. **مفتاح المطوّر**: لما يطلب منك، اكتب الرمز اللي في شاشة Developer Mode.
٢. **ربط الريموت**: بتطلع رسالة على التلفزيون، اختار **قبول (Accept)**.
٣. **رمز الجوال**: ينسوّى رمز من ٤ أرقام لتطبيق الجوال.

كل شي ينحفظ في `.majlis/majlis.json` على كمبيوترك. فيه مفاتيح تلفزيونك، فخلّه خاص (هو أصلاً مستثنى من Git).

## ٤. التركيب

<div dir="ltr">

```bash
npm run deploy -- --name majlis
```

</div>

ينركّب «مجلس» وينفتح على التلفزيون. أول تشغيل ياخذ ثواني لين يتصل المساعد.

## ٥. جهّز جوالك

١. من جوال متصل بنفس الواي فاي، افتح `http://<عنوان-التلفزيون>:8090` (السكربت يطبع لك العنوان بالضبط).
٢. اكتب الرمز. تلقاه بعد في التلفزيون داخل **مجلس ← الإعدادات**.
٣. ثبّته على الشاشة الرئيسية:
   - **آيفون**: من Safari، اضغط زر المشاركة ثم **إضافة إلى الشاشة الرئيسية**
   - **أندرويد**: من Chrome، افتح القائمة ⋮ ثم **إضافة إلى الشاشة الرئيسية**

بعدها من الجوال:
- **الإعدادات**: اختار **مدينتك** لمواقيت الصلاة والطقس
- **الضيوف**: أضف **واي فاي الضيوف**

## ٦. إعدادات ننصح فيها في التلفزيون

هذي إعدادات LG نفسها، مو «مجلس»، بس تحسّن التجربة:

| الإعداد | مكانه | ليش |
|---|---|---|
| Quick Start+ ← تشغيل | الإعدادات ‹ عام ‹ الأجهزة ‹ إدارة التلفاز | يشتغل بثانية ويخلي «مجلس» شغّال |
| Home Promotion ← إيقاف | الإعدادات ‹ عام ‹ النظام ‹ إعدادات إضافية ‹ إعدادات الصفحة الرئيسية | إعلانات أقل في شاشات LG |
| Home Auto Launch ← إيقاف | نفس المكان | التلفزيون يبدأ على آخر مدخل بدل شاشة LG |
| عنوان IP ثابت للتلفزيون | الراوتر (حجز DHCP) | عنوان الجوال ما يتغير أبد |

## أكثر من تلفزيون

كرر الخطوات ١ و٣ و٤ باسم ثاني:

<div dir="ltr">

```bash
npm run setup -- --name bedroom --ip 192.168.1.41
npm run deploy -- --name bedroom
```

</div>

كل تلفزيون له إعداداته وصوره ورمزه.

## التحديث

<div dir="ltr">

```bash
git pull
npm run deploy -- --name majlis
```

</div>

إعداداتك وصورك تبقى على التلفزيون.

## الحذف

<div dir="ltr">

```bash
npm run remove -- --name majlis
```

</div>

أو اطفِ وضع المطوّر من التلفزيون، وينحذف كل تطبيقات المطوّر.
