# Other TVs

[العربية](../ar/other-tvs.md) · [Back to README](../../README.md)

Majlis runs on LG webOS today. Other brands need their own version, because each one opens up different things to outside apps.

| Platform | Brands | Can it run Majlis? | Notes |
|---|---|---|---|
| **LG webOS** | LG | Yes | Full version: background helper, phone app, Home button, notifications over apps |
| **Android TV / Google TV** | Sony, TCL, Hisense (Google TV models), Philips, Xiaomi, Toshiba, Sharp; Chromecast with Google TV, Google TV Streamer, Nvidia Shield | Planned | Android allows a real replacement home screen, so the Home button would open Majlis directly. Install would be one APK file. |
| **Fire TV** | Amazon Fire TV sticks and Fire TV Edition TVs | Planned, with the Android version | Same APK; Amazon makes replacing the home screen harder |
| **Samsung Tizen** | Samsung | Possible, limited | Samsung's Developer Mode can install web apps, but they can't run a background helper. A Samsung version would have the screen (prayer, Quran, calm mode) but not the phone control or notifications over other apps. Installing needs Tizen Studio and a Samsung certificate. |
| **Roku, Hisense VIDAA, Panasonic** | — | No | These don't allow installing your own apps in a practical way |

## Any TV, with a small box

Once the Android version exists, any TV with an HDMI port can run Majlis through an Android TV box or a Google TV / Fire TV stick. That will be the easiest route for TVs that aren't LG.

## Helping

If you have a Samsung or Android TV and want to help test a port, open an issue with your model.
